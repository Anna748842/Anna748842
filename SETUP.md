# 🚀 Anand Kumar Das — Animated GitHub Profile

This folder is ready to upload to your **GitHub profile repository**.

## 1. Create/Open the profile repository

Open:

`https://github.com/Anna748842`

The repository must be named exactly:

`Anna748842`

It should be **public**.

## 2. Upload the files

Upload the whole structure:

```text
Anna748842/
├── README.md
├── assets/
│   ├── hero.svg
│   ├── tech-stack.svg
│   ├── socials.svg
│   ├── project-strip.svg
│   ├── animated-separator.svg
│   └── footer.svg
└── .github/
    └── workflows/
        └── snake.yml
```

## 3. Run the snake animation

After uploading:

1. Open the repository.
2. Open the **Actions** tab.
3. Select **Generate GitHub Contribution Snake**.
4. Click **Run workflow**.
5. Wait for the workflow to complete.
6. A branch named `output` should be created.
7. Refresh your profile.

The README references:

```text
https://raw.githubusercontent.com/Anna748842/Anna748842/output/github-contribution-grid-snake-dark.svg
```

## 8. If an image does not show

Check:

- repository is public
- the file path is correct
- the `output` branch exists for the snake
- GitHub Actions completed successfully
- the external stats provider is available

For the snake, manually run the workflow once after the first upload.
